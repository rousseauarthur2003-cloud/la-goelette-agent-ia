# Architecture cible

1. Interface Next.js : navigation, tableaux de bord et fiches agents.
2. Moteur Phaser : carte, collisions, caméra, personnages et interactions.
3. Backend métier : agents, départements, missions et permissions.
4. Base PostgreSQL : données persistantes et historiques.
5. Canal temps réel : diffusion des événements de statut.
6. Orchestrateur IA : planification, délégation, exécution et contrôle.

Les actions sensibles (dépenses, engagements, publications sensibles, changements de prix et actions irréversibles) doivent être soumises à des règles de validation explicites.
